AMFI Mutual Fund Allocation & SIP Planner
An Excel-based Mutual Fund Analysis and Investment Recommendation System

Technology: Microsoft Excel 2021
Domain: Financial Analysis | Mutual Fund Research | Investment Planning

1. Project Overview
The AMFI Mutual Fund Allocation & SIP Planner is an Excel-based financial analysis project developed to evaluate mutual funds and support investment allocation decisions.

The project uses a database of approximately 180 mutual funds and a recommendation engine that evaluates funds using performance and risk indicators.

2. Key Features
Mutual fund database covering approximately 180 funds.
Automated mutual fund recommendation engine.
Fund evaluation using Sharpe Ratio, Sortino Ratio and Alpha.
Risk-based fund classification.
Lump-sum investment planning.
Systematic Investment Plan (SIP) calculator inputs.
Goal-based investment planning.
Interactive Excel dashboard with charts and summary metrics.
3. Investment Inputs
Users can provide:

Lump-sum investment amount.
Monthly SIP amount.
Investment horizon.
Expected inflation.
Financial investment goal.
4. Recommendation Methodology
The recommendation engine uses a scoring approach based on three financial performance indicators:

Sharpe Ratio: Evaluates risk-adjusted returns.
Sortino Ratio: Measures returns relative to downside risk.
Alpha: Evaluates performance relative to a benchmark.
The combined scoring approach helps rank and classify mutual funds.
