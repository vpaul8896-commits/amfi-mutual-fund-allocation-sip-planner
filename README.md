
# AMFI Mutual Fund Allocation & SIP Planner

**Tools:** Microsoft Excel 2021

## Overview
An Excel-based mutual fund analysis and investment planning tool designed to evaluate approximately 180 mutual funds and generate fund recommendations based on performance and risk indicators.

## Key Features
- Mutual fund database with 180+ funds.
- Automated fund recommendation engine.
- Fund scoring using Sharpe Ratio, Sortino Ratio and Alpha.
- Risk-based fund classification.
- Lump-sum and SIP investment planning.
- Goal-based investment allocation.
- Interactive Excel dashboard.

## Investment Goals
Child Education | House Purchase | Tax Saving | Wealth Creation | Retirement

## Project Structure
- `Excel_Model/` – Excel workbook.
- `Screenshots/` – Project dashboard and model screenshots.
- `Documentation/` – Project details.
